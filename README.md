# AI Coffee Machine Using Hand Gesture Recognition

## Overview

The AI Coffee Machine is a computer vision-based application that enables contactless coffee selection through hand gesture recognition. The system uses a webcam to capture hand movements, detects hand landmarks using MediaPipe, and maps predefined gestures to different coffee options.

This project demonstrates the practical application of Artificial Intelligence, Computer Vision, and Human-Computer Interaction in creating smart and touch-free ordering systems.

## Features

* Real-time hand gesture recognition
* Contactless coffee ordering
* Live webcam integration
* Hand landmark detection using MediaPipe
* Fast and user-friendly interaction
* Low-cost implementation using standard hardware

## Technologies Used

* Python
* OpenCV
* MediaPipe
* NumPy

## System Workflow

1. Capture live video from webcam
2. Detect hand landmarks using MediaPipe
3. Analyze finger positions
4. Recognize predefined gestures
5. Map gestures to coffee selections
6. Display order confirmation
